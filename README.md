# Irkutsk Antibiotic Dashboard

Interactive status dashboard tracking antibiotic retail pressure, public health surveillance, and epidemic monitoring updates for Irkutsk and Shelekhov.

## Live Demo

- **Shareable Live Page**: [https://21e8-miner.github.io/irkutsk-antibiotic-dashboard/](https://21e8-miner.github.io/irkutsk-antibiotic-dashboard/)

## Features

- **KPI Cards**: Real-time snapshot of confirmed plague secondary cases, observed contacts, status indicators, and pharmacy restock windows.
- **Retail Pressure Matrix**: Drug availability breakdown across Irkutsk vs. Shelekhov (Doxycycline, Ciprofloxacin, Levofloxacin, Gentamicin, Moxifloxacin, Streptomycin).
- **Situation Updates**: Key surveillance developments, lab test results, and institutional commission findings.
- **Responsive Dark Theme**: Lightweight single-file HTML/CSS dashboard optimized for desktop and mobile displays.

## Local Viewing

Open `index.html` directly in any modern browser:

```bash
open index.html
```
